# Валидация спроса и семантическое ядро для ассортимента Soliton

Дата исследования: 2026-05-12. География: Россия (`225`).
Источники поисковых данных: Yandex Wordstat API `/v1/topRequests` и `/v1/dynamics`. Период динамики: 2024-05-01 — 2026-04-30.

## Executive memo

- Решение: `go and scale via SEO`.
- Уверенность: `high`, потому что Wordstat API доступен, регион проверен, есть 24-месячная динамика и рыночный контекст по ЦОД/PDU.
- Основной вывод: потребность подтверждена не как брендовый спрос на Soliton, а как категорийный спрос на PDU/блоки розеток для 19-дюймовых шкафов, серверных стоек и ЦОД.
- Рекомендуемая рамка: «PDU и блоки розеток для 19-дюймовых серверных шкафов: Schuko, IEC C13/C19, 16A/32A, вертикальные, трехфазные, измерительные и управляемые».
- Главный риск: брендовый спрос Soliton почти отсутствует; рост нужно брать через категорийные, характеристические и сравнительные страницы, а не через брендовые запросы.

## Подтвержденные факты

- В ассортиментной карте Soliton зафиксировано 66 товаров: 10/19 дюймов, вертикальные 16A/32A, трехфазные, управляемые/измерительные PDU, сетевые фильтры с УЗИП.
- Wordstat: собрано 63 seed-запроса, 223 релевантные фразы ядра, 10 кластеров спроса.
- Рыночный контекст: российские и глобальные источники подтверждают рост нагрузки на стойки, спрос на ЦОД и интерес к мониторингу питания.
- Прямой брендовый спрос слабый: `солитон блок розеток` = 17 показов в текущей проверке, `soliton pdu` = 7, `soliton блок розеток` = 2.

## Product reframing

- Исходная рамка «товары Soliton» слабая для спроса: бренд почти не ищут.
- Рабочая рамка для сайта: категорийная, через PDU/блоки розеток для серверных шкафов и стоек.
- Соседний спрос «серверные шкафы / стойки 19”» крупнее прямого спроса на PDU, но это не продуктовый pivot. Это SEO-мост: нужны use-case страницы «как подобрать блок розеток/PDU для серверного шкафа 19”», «питание стойки 42U», «PDU для ЦОД».
- Прямые money-кластеры: PDU, блоки розеток 19”/1U, Schuko/IEC C13/C19, 16A/32A, вертикальные PDU, мониторинг/управление, трехфазные PDU.

## Ограничения

- Wordstat не дает чистый рынок: высокочастотные фразы пересекаются, поэтому кластерные суммы нельзя складывать как независимый объем.
- SERP вручную не разбирался: возможны маркетплейсы, агрегаторы и сильные поставщики в выдаче.
- Часть соседнего спроса относится к шкафам и стойкам, которых нет в ассортименте Soliton; использовать его нужно только как use-case и перелинковку к PDU.
- Низкочастотные B2B-кластеры вроде трехфазных и управляемых PDU могут быть ценнее по маржинальности, чем по объему показов.
