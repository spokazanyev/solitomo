# Контент И ТЗ

## Назначение

Рабочий документ для постановки задач на тексты, таблицы характеристик, карточки товаров и информационные блоки.

## Общие Правила Контента

- Писать для B2B-аудитории: инженеры, интеграторы, закупщики, администраторы серверных.
- Сначала техническая ясность, затем SEO.
- Не раздувать страницы общими фразами.
- В каждой категории явно указывать: ток, напряжение, тип розеток, монтаж, количество розеток, кабель/ввод, защита, мониторинг, документы.
- Для низкочастотных, но дорогих кластеров делать технически точные страницы.

## Первые Контентные Задачи

1. Унифицировать характеристики всех 66 товаров.
2. Подготовить тексты для категорий `PDU`, `Блоки розеток 19” 1U`, `Schuko`, `IEC C13/C19`, `16A`, `32A`.
3. Подготовить use-case текст `PDU для серверного шкафа 19”`.
4. Подготовить FAQ для PDU и блоков розеток.
5. Проверить карточки без категории на сайте и определить, куда их включить.
