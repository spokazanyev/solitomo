# Спецификация Позиционирования И Копирайтинга Soliton

Дата: 2026-05-14.

SDD feature: `specs/002-positioning-copy-system`.

## Executive Summary

Soliton нужно позиционировать как российского производителя решений для распределения питания в стойках, серверных шкафах и технической инфраструктуре, а не как обычный интернет-магазин блоков розеток.

Основная идея:

**Soliton помогает подобрать и поставить PDU, блоки розеток и силовые решения для стоек и серверных с технической точностью, документами, поддержкой юрлиц и проверенной российской производственной базой.**

Тексты должны соединять три слоя:

- техническая точность: ток, розетки, монтаж, ввод, защита, документы;
- доверие: 19-летняя история, российское производство, реестр, надежность в эксплуатации;
- конверсия: подбор, запрос КП, счет для юрлица, доставка, помощь с аналогами.

## Positioning Statement

Короткая версия:

**Soliton - российский производитель PDU и блоков розеток для стоек, серверных шкафов и технической инфраструктуры.**

Расширенная версия:

**Soliton производит и поставляет PDU, блоки розеток и силовые решения для 19-дюймовых стоек, серверных шкафов и объектов технической инфраструктуры. Компания работает на рынке более 19 лет, развивает российское производство и помогает заказчикам подобрать оборудование по току, типу розеток, монтажу, нагрузке и требованиям проекта.**

Версия для B2B:

**Для юрлиц Soliton помогает подобрать PDU под ТЗ, подготовить КП, счет и документы, согласовать доставку по России и подобрать аналоги при замене оборудования.**

## Core Promise

Покупатель получает не просто блок розеток, а корректно подобранное решение для питания стойки:

- по форм-фактору;
- по типу розеток;
- по току и нагрузке;
- по вводу;
- по защите;
- по сценарию эксплуатации;
- с документами и возможностью получить КП.

## Message Pillars

## 1. Российский Производитель С Историей

Смысл:

Soliton не выглядит как случайный продавец из выдачи. Это производитель с известной 19-летней историей.

Безопасная формулировка:

**Soliton - российский производитель с более чем 19-летней историей в оборудовании для распределения питания.**

Где использовать:

- главная;
- B2B-страница;
- блок доверия;
- карточки товаров;
- КП/о компании.

Proof requirement:

- год основания;
- страница "О компании";
- регистрационные/производственные данные;
- история компании.

## 2. Российское Производство И Реестр

Смысл:

Для B2B и госсектора важно, что продукция/фильтры российского производства и внесены в реестр.

Безопасная формулировка до проверки:

**Для отдельных товарных линий доступны изделия российского производства; сведения о включении в реестр нужно указывать по конкретным моделям и документам.**

Публичная формулировка после проверки:

**[Название линейки] производится в России и включена в [название реестра], запись [номер/ссылка].**

Где использовать:

- B2B;
- карточки конкретных товаров;
- документы;
- страницы для закупщиков.

Proof requirement:

- точное название реестра;
- номер записи;
- ссылка;
- список моделей/линеек, к которым относится утверждение.

## 3. Надежность, Проверенная Эксплуатацией

Смысл:

Пользователь должен понимать, что оборудование не новое и не экспериментальное.

Безопасная формулировка:

**Надежность продукции Soliton подтверждается многолетней эксплуатацией у пользователей и повторными поставками.**

Более сильная формулировка после доказательств:

**Оборудование Soliton используется в проектах более 19 лет; типовые модели поставляются повторно и применяются в стойках, серверных и технических помещениях.**

Proof requirement:

- кейсы;
- отзывы;
- повторные поставки;
- гарантийная статистика, если доступна.

## 4. Качество Конструктива И Изготовления

Смысл:

Проектная ценность: продукция воспринимается как сопоставимая с известными зарубежными аналогами.

Безопасная формулировка:

**По оценкам пользователей, конструктив и качество изготовления Soliton сопоставимы с сильными зарубежными аналогами.**

Осторожно:

Не писать "не уступает APC/APS" как прямое утверждение без подтвержденных отзывов, тестов или юридической проверки.

Proof requirement:

- уточнить бренд: APS или APC;
- собрать отзывы пользователей;
- получить разрешение на публикацию;
- если делается сравнение, сравнивать конкретные параметры, а не бренд целиком.

## 5. Технический Подбор Вместо Случайной Покупки

Смысл:

Ошибиться с PDU легко: тип розеток, ток, ввод, монтаж, нагрузка, вертикальный/горизонтальный формат.

Формулировка:

**Поможем подобрать PDU по току, типу розеток, монтажу, вводу и нагрузке стойки.**

Где использовать:

- главная;
- категории;
- карточки;
- B2B;
- RFQ.

## Tone Of Voice

## Основной Тон

- технически точный;
- спокойный;
- уверенный;
- без рекламного шума;
- с уважением к инженеру и закупщику;
- с конкретикой вместо общих обещаний.

## Как Писать

Писать:

- "8 розеток Schuko, монтаж 19", 1U, вход C14";
- "подходит для серверных шкафов и телеком-стоек";
- "запросите КП с количеством и городом доставки";
- "уточним совместимость по току, вводу и типу розеток";
- "добавьте артикулы в запрос КП".

Не писать:

- "лучшие решения для бизнеса";
- "инновационное оборудование нового поколения";
- "максимальное качество по выгодной цене";
- "широчайший ассортимент";
- "уникальные PDU";
- "аналог APC" без доказательств.

## SEO And Intent Rules

Тексты должны закрывать конкретный поисковый интент.

| Cluster | User Intent | Copy Rule |
|---|---|---|
| PDU / блоки распределения питания | Понять и выбрать класс PDU | Объяснить типы: базовые, измерительные, мониторинговые, управляемые. |
| Блоки розеток 19" / 1U | Найти стоечный блок нужного размера | Сразу указать 19", 1U, количество розеток, монтаж. |
| Schuko / IEC C13 / C19 | Подобрать совместимый тип розеток | Объяснить, для какого оборудования подходит каждый тип. |
| 16A / 32A | Проверить ток и нагрузку | Не обещать мощность без расчета; давать ориентиры и CTA на подбор. |
| Вертикальные PDU | Питание стойки 0U/42U | Указать экономию места в юнитах и сценарии применения. |
| Мониторинговые/управляемые PDU | Контроль нагрузки и удаленное управление | Использовать только для моделей с такими функциями. |
| Серверные шкафы / ЦОД | Решить задачу питания инфраструктуры | Писать use-case текст, вести к подбору и КП. |

Goal:

Снять сомнения и поддержать SEO.

Rules:

- вопросы должны быть практическими;
- ответы 40-90 слов;
- не писать рекламные ответы;
- ссылаться на категорию или подбор.

Examples:

- Чем PDU отличается от обычного блока розеток?

- Как выбрать PDU на 16A или 32A?
- Можно ли получить счет для юрлица?
- Какие документы доступны на продукцию?

## Technical Copy Rules

1. Всегда различать PDU, блок розеток, сетевой фильтр и УЗИП.
2. Не писать "мощность" без тока, напряжения и условий расчета.
3. Не писать "подходит для ЦОД" для слабых/бытовых моделей без параметров.
4. Для C13/C19/Schuko объяснять совместимость простым языком.
5. В карточке сначала давать параметры, потом маркетинговые преимущества.
6. В категориях избегать воды; каждый абзац должен помогать выбрать.
7. Если есть документы, ссылаться на них.
8. Если данных нет, писать "уточните у менеджера", а не придумывать.

## Banned And Discouraged Copy

Запрещено или нежелательно:

- "лучший";
- "уникальный";
- "идеальный";
- "инновационный" без объяснения;
- "премиальное качество" без доказательства;
- "аналог APC" без подтверждения;
- "для любых задач";
- "гарантированная надежность";
- "максимальная безопасность";
- SEO-повторы вида "купить PDU PDU блок PDU".
