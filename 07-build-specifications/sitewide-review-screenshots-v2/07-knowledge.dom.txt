  - article:
    - text: Материал по выбору PDU
    - paragraph: "Выбор PDU начинается не с количества розеток, а с задачи стойки: какое оборудование подключается, какая суммарная нагрузка, где будет монтаж и какие документы нужны для закупки."
    - heading "Определите монтаж" [level=2]
    - paragraph: Для компактных стоек часто выбирают горизонтальный блок 19 дюймов 1U. Для высокой плотности и стоек 42U удобнее вертикальные PDU, которые не занимают юниты.
    - heading "Проверьте ток и ввод" [level=2]
    - paragraph: 16A подходит для типовых задач, 32A и трехфазные решения рассматривают для высокой нагрузки. Расчет лучше делать по оборудованию с запасом и учетом схемы питания.
    - heading "Сверьте розетки" [level=2]
    - paragraph: Schuko используют для оборудования с бытовыми вилками, IEC C13/C19 - для серверного и сетевого оборудования. Смешанные PDU удобны в стойках с разными типами устройств.
    - complementary:
      - text: Следующий шаг

    - heading "Что отправить для подбора?" [level=2]
    - paragraph: Список оборудования, тип стойки, количество юнитов, желаемый монтаж, ток, тип розеток, город и срок поставки.

    - paragraph: "Часто можно, но замену нужно делать по конкретным параметрам: ток, розетки, ввод, габариты, функции и документы."
