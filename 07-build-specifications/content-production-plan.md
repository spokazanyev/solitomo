# Content Production Plan

Дата: 2026-05-15.

## Назначение

План задает, как производить тексты для сайта Soliton без хаоса, повторов и неподтвержденных технических утверждений. Документ используется Codex как основа для следующих задач по SEO-текстам, карточкам, FAQ, use-case страницам и базе знаний.

## Принципы

- Писать сначала для инженера и закупщика, потом для поискового робота.
- Каждый текст должен вести к действию: открыть категорию, выбрать товар, запросить КП или отправить ТЗ.
- Не использовать общие фразы без технического смысла.
- Не публиковать claims о реестре, сертификатах, наличии, точных сроках или сравнении с APC/APS без доказательств.
- Для каждой страницы держать один основной интент и не смешивать коммерческий, информационный и B2B-сценарий без структуры.

## Шаблон Категории

1. H1 и короткое объяснение интента.
2. Какие товары входят в категорию.
3. Основные параметры выбора: монтаж, ток, розетки, ввод, защита, мониторинг.
4. Товарный листинг.
5. Сравнение параметров.
6. FAQ.
7. Внутренние ссылки на смежные категории, use-case и knowledge.
8. CTA: каталог, подбор, КП.

## Шаблон Карточки Товара

1. Название и SKU.
2. Краткое назначение товара.
3. Ключевые характеристики.
4. Для какой стойки или задачи подходит.
5. Что уточнить перед заказом.
6. Документы.
7. Похожие товары.
8. CTA: запрос КП, совместимость, документы.

## Шаблон Knowledge-Статьи

1. Короткое определение.
2. Практический выбор или проверка параметров.
3. Типовые ошибки.
4. FAQ.
5. Ссылки на категории и подбор.

## Claim-Control

| Claim | Где можно использовать | Что нужно для усиления |
|---|---|---|
| 19-летняя история | Главная, B2B, компания | Год основания, история, реквизиты |
| Российское производство | Главная, B2B, документы | Документы по производству и линейкам |
| Реестр | Документы, B2B, карточки после проверки | Номер записи, ссылка, список моделей |
| Надежность проверена годами | Главная, B2B, карточки осторожно | Кейсы, отзывы, повторные поставки |
| Сопоставимость с зарубежными аналогами | Только осторожная формулировка | Отзывы, тесты, сравнение параметров |

## Production Workflow

1. Выбрать страницу из приоритета P1/P2.
2. Зафиксировать основной интент и целевые запросы.
3. Собрать товарные и документальные источники.
4. Написать первый текст по шаблону.
5. Проверить технические claims.
6. Проверить внутренние ссылки и CTA.
7. Добавить/обновить FAQ.
8. Выполнить smoke-test страницы.
