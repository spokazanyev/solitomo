# Homepage B2B Trust Specification

Дата: 2026-05-15.

## Назначение

Документ фиксирует реализацию главной страницы и B2B/trust-блоков Soliton. Цель этапа - сделать сайт похожим на современный ecommerce и B2B-сайт производителя, а не только на набор SEO-посадочных и карточек.

## Реализованный Базис

Кодовая реализация:

- `apps/web/src/components/SeoLandingPage.tsx` - product/manufacturer hero panel для главной.
- `apps/web/src/components/page-templates.tsx` - homepage proof metrics, real featured products, use-case cards, усиленный B2B template.
- `apps/web/src/lib/seo/template-content.ts` - trust signals, home metrics, use cases, B2B trust points.

## Homepage Requirements

Главная должна показывать:

- что Soliton производит PDU и блоки розеток для стоек;
- реальные product visuals из ассортимента;
- 19-летнюю историю;
- российское производство;
- связь с реестром и документами;
- путь в каталог;
- путь в инженерный подбор;
- путь в B2B-заявку;
- сценарии применения: серверные шкафы, ЦОД/проекты, закупки/интеграторы.

## B2B Requirements

B2B-раздел должен объяснять:

- какие данные нужны для КП;
- как отправить ТЗ;
- какие параметры PDU нужно указать;
- почему проектная заявка важнее случайной покупки;
- где получить документы для закупки;
- как связать каталог, документы и запрос КП.

## Claim-Control

Можно использовать как общее позиционирование:

- `19-летняя история`;
- `Российское производство`;
- `внесение в реестр`;
- `надежность проверена годами`;
- `конструктив и качество изготовления сопоставимы с зарубежными аналогами по оценкам пользователей`.

Но для SKU-level карточек и документов нужны подтверждения:

- конкретная запись реестра;
- сертификат;
- паспорт;
- источник отзыва или оценки;
- дата и версия документа.

## Conversion Logic

Главная не должна пытаться продать все сразу. Она распределяет трафик:

- коммерческий спрос -> каталог;
- инженерный спрос -> подбор;
- корпоративный спрос -> B2B/RFQ;
- закупочный спрос -> документы и КП;
- информационный спрос -> knowledge pages.

## Validation

Проверки:

```bash
pnpm lint
pnpm typecheck
DATABASE_URI=postgres://soliton:soliton_dev_password@localhost:5432/soliton PAYLOAD_SECRET=development-secret pnpm build
curl -sI http://localhost:3000/
curl -sI http://localhost:3000/b2b/
```
