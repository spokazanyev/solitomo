## Troubleshooting — типовые статусы и что делать

| Статус (GSC / Вебмастер) | Причина | Действие |
|---|---|---|
| «Crawled — currently not indexed» / «Просканировано, не проиндексировано» | Тонкий/слабый контент (часто тонкие PDU-карточки) | Расширить описание товара (≥200 слов), добавить уникальную пользу. Массово — отдельная контент-задача (deferred п.2/7) |
| «Discovered — currently not indexed» | Бот в очереди, ещё не обошёл | Подождать; повторный IndexNow ping (`pnpm indexnow:bulk`); Request indexing для приоритетных URL |
| «Duplicate without user-selected canonical» | Несколько URL-вариантов на один контент | Проверить canonical (должен быть на чистый URL без query); у нас canonical уже корректные |
| «Soft 404» | Пустая/обрезанная страница отдаёт 200 | Проверить контент страницы; если правда пусто — naindex или наполнить |
| «Заблокировано в robots.txt» | URL под Disallow | Проверить, что заблокирован только мусор (/cart/, /checkout/, query); ценные URL не должны попадать |
| Sitemap «Не удалось получить» | Транзиент при деплое / редирект | Перепроверить `curl -sI https://pdumarket.ru/sitemap.xml` (200, без редиректа на зарегистрированном хосте) |

## Полезные команды (read-only проверки прода)

```bash
# Сколько URL и товаров в боевом sitemap
curl -s https://pdumarket.ru/sitemap.xml | grep -c '<loc>'
curl -s https://pdumarket.ru/sitemap.xml | grep -c '/product/'

# robots.txt здоров
curl -sI https://pdumarket.ru/robots.txt   # 200, text/plain, без редиректа

# Сколько страниц в индексе (ручная прикидка через оператор site:)
#   Google:  site:pdumarket.ru
#   Яндекс:  site:pdumarket.ru  (или host:pdumarket.ru)

# Повторный массовый IndexNow-push (Яндекс/Bing)
SITE_URL=https://pdumarket.ru pnpm --filter @soliton/web indexnow:bulk
```
