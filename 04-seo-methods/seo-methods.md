# Методы Поисковой Оптимизации

## Цель

Сформировать SEO-систему для привлечения органического B2B-трафика по PDU, блокам розеток и смежным задачам электропитания серверных шкафов.

## Основные Методы

## 1. Кластерная Структура

Страницы создаются под кластеры, а не под отдельные случайные ключи:

- PDU / блоки распределения питания.
- Блоки розеток 19” / 1U.
- Schuko.
- IEC C13 / C19.
- 16A / 32A.
- Вертикальные PDU.
- PDU с мониторингом / управлением.
- Трехфазные PDU.
- PDU для серверного шкафа / стойки.

## 2. Техническая Нормализация Карточек

Для каждой карточки должны быть заполнены:

- артикул;
- тип монтажа;
- ток и напряжение;
- количество и тип розеток;
- кабель / ввод / вилка;
- защита;
- мониторинг / управление;
- габариты;
- документы;
- изображения.

## 3. Внутренняя Перелинковка

Связки:

- товар -> категория;
- категория -> подкатегории по характеристикам;
- use-case -> категории;
- категория -> FAQ;
- товар -> похожие товары;
- сравнение -> релевантные категории.

## 4. Страницы Под Смежный Спрос

Спрос по `серверный шкаф`, `стойка 19`, `шкаф 19` не должен вести на страницы продажи шкафов. Эти запросы используются как вход в задачу подбора PDU:

- PDU для серверного шкафа.
- Блок розеток для стойки 19”.
- Питание стойки 42U.

## 5. Snippet И Метаданные

Для категорий:

- Title: ключ + технический модификатор + бренд.
- Description: назначение + основные параметры + CTA.
- H1: точное коммерческое название категории.

## 6. Измерение Результата

Отслеживать:

- позиции по кластерам;
- органические переходы;
- заявки;
- конверсию страниц категорий;
- долю трафика на карточки;
- запросы без посадочной страницы.

## 7. Первичные KPI

Ориентиры после внедрения:

- 1 300-1 400 органических переходов в месяц: консервативно.
- 5 500-6 000 органических переходов в месяц: базовый товарный сценарий.
- до 9 000-10 000 переходов в месяц: с use-case страницами под серверные шкафы и стойки.
