# Roadmap

## Этап 1. Нормализация Данных

- Проверить все 66 товаров.
- Убрать или исправить товары без категории.
- Унифицировать названия, артикулы и характеристики.
- Проверить документы и изображения.

## Этап 2. Архитектура Каталога

- Утвердить структуру категорий.
- Определить URL.
- Разнести товары по категориям и подкатегориям.
- Спроектировать фильтры.
- Спроектировать управляемые фильтры в админке: группы, поля, опции, пресеты, счетчики, индексируемость.
- Предусмотреть добавление и отключение фильтров без правки React-кода, если фильтр связан с controlled attribute.

## Этап 2A. Agent-Ready Админка

- Добавить в админку товары, категории, документы, медиа, фильтры и SEO-поля.
- Добавить `admin-change-log`.
- Добавить draft/diff/preview workflow.
- Добавить единый контекст проекта для Codex, Claude Code и других агентов.
- Добавить scripts: `agent:context`, `export:catalog`, `validate:catalog`, `validate:seo`, `validate:schema`, `smoke:public-pages`, `agent:propose-change`, `agent:apply-change`.
- Все массовые изменения выполнять через dry-run/apply.

## Этап 2B. MCP, Если Понадобится

- Сначала реализовать Payload collections, API и scripts.
- Затем при необходимости сделать локальный MCP-сервер поверх Payload/scripts.
- MCP должен давать агентам tools для контекста проекта, поиска записей, draft-изменений, проверок, preview, audit log и публикации после подтверждения.
- MCP не должен быть обязательным для MVP.

## Этап 3. SEO-Посадочные Страницы

- Подготовить страницы PDU.
- Подготовить страницы 19” 1U.
- Подготовить страницы Schuko и IEC C13/C19.
- Подготовить страницы 16A и 32A.
- Подготовить страницы вертикальных, мониторинговых и трехфазных PDU.

## Этап 4. Карточки Товаров

- Переписать карточки по единому шаблону.
- Добавить таблицы характеристик.
- Добавить блоки применения.
- Добавить документы и похожие товары.

## Этап 5. Use-Case И Сравнения

- PDU для серверного шкафа 19”.
- Питание стойки 42U.
- PDU для ЦОД.
- Сравнение базовых, измерительных и управляемых PDU.
- Сравнение с конкурентными PDU, если это юридически и коммерчески допустимо.

## Этап 6. Запуск И Измерение

- Настроить аналитику.
- Проверить индексацию.
- Отследить первые позиции.
- Собрать запросы из Search Console / Яндекс Вебмастера.
- Доработать страницы по фактическим показам и CTR.
