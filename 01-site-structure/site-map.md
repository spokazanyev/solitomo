# Проект Структуры Сайта

Подробная целевая архитектура нового сайта вынесена в файл [target-site-structure.md](target-site-structure.md).

## Назначение

Документ для проектирования будущей структуры сайта: разделы, категории, посадочные страницы, связи между страницами и приоритеты внедрения.

## Базовая Логика

Сайт должен строиться не как простой список товаров, а как B2B-каталог PDU и блоков розеток для серверных шкафов, стоек и ЦОД.

## Верхний Уровень

- Главная
- Каталог PDU и блоков розеток
- Подбор PDU для серверного шкафа / стойки
- Решения для ЦОД и серверных
- Документы и сертификаты
- О компании / производство
- Контакты / заявка

## Каталог

- PDU / блоки распределения питания
- Блоки розеток 19” 1U
- Блоки розеток 10” 1U
- Вертикальные PDU / 0U / 42U
- Блоки розеток 16A
- Блоки розеток 32A
- Schuko PDU
- IEC C13 / IEC C19 PDU
- Измерительные PDU
- Управляемые PDU
- PDU с мониторингом
- Трехфазные PDU
- PDU / блоки розеток с УЗИП
- Сетевые фильтры для стойки 19”

- PDU для серверного шкафа 19”
- Блок розеток для стойки 19”

- PDU для телекоммуникационного шкафа
- Как выбрать PDU: Schuko, IEC C13, IEC C19

## Сравнительные Страницы

- Soliton / отечественные PDU как альтернатива APC PDU
- PDU Soliton и Hyperline: сравнение подходов
- Базовые, измерительные и управляемые PDU: что выбрать

## Приоритет Внедрения

1. Категория `PDU / блоки распределения питания`.
2. Категория `Блоки розеток 19” 1U`.
3. Категории по типу розеток: Schuko, IEC C13/C19.
4. Категории по току: 16A, 32A.
5. Вертикальные PDU.
6. Измерительные / мониторинговые / управляемые PDU.
7. Use-case страницы для серверных шкафов и стоек.
8. Сравнительные страницы.

## Текущий Реализованный SEO-Каркас

Дата обновления: 2026-05-15.

В рамках feature `006-seo-site-structure` в коде создан начальный SEO-реестр из 36 индексируемых URL. Он используется для:

- генерации `sitemap.xml`;
- генерации `robots.txt`;
- canonical URL;
- metadata;
- BreadcrumbList JSON-LD;
- статических route skeleton pages.

Канонический формат URL: с завершающим `/`.

Реализованные разделы:

- `/catalog/.../` - 11 коммерческих категорий.
- `/solutions/.../` - 4 use-case страницы.
- `/b2b/.../` - 5 корпоративных страниц.
- `/knowledge/.../` - 9 информационных страниц.
- `/documents/.../` - 3 страницы документов.
- `/company/.../` - 3 страницы доверия и контактов.

Подробная матрица: `07-build-specifications/seo-landing-matrix.md`.

Технические SEO-правила: `07-build-specifications/seo-technical-spec.md`.
