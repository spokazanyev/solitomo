# Целевая Структура Нового Сайта Soliton

## Цель Сайта

Создать современный интернет-магазин и B2B-каталог PDU, блоков розеток и решений электропитания для серверных шкафов, стоек и ЦОД.

Сайт должен решать две задачи одновременно:

- Продавать частным и малым покупателям через понятный каталог, фильтры, цены, корзину и быстрый заказ.
- Привлекать корпоративных клиентов под проекты, тендеры, регулярные поставки и контрактное производство.

## Основная SEO-Логика

Продвижение строится не вокруг бренда Soliton, а вокруг категорийного спроса:

- `pdu`
- `блок розеток`
- `блок розеток 19`
- `блок розеток 1u`
- `блок розеток pdu`
- `блок розеток schuko`
- `pdu c13`
- `pdu c19`
- `pdu 16a`
- `pdu 32a`
- `вертикальный pdu`
- `pdu с мониторингом`
- `управляемый pdu`
- `трехфазный pdu`
- `pdu для серверного шкафа`
- `блок розеток для стойки 19`

Брендовый спрос Soliton слабый, поэтому бренд нужно усиливать через экспертность, производство, документацию, ассортимент и попадание в категорийные запросы.

## Технические SEO-Требования

- ЧПУ URL без параметров для посадочных страниц.
- Canonical для фильтров и пагинации.
- XML sitemap по типам страниц.
- HTML sitemap.
- Breadcrumbs.
- Уникальные title/description/H1.
- Индексируемые страницы только с достаточным контентом и товарами.
- Быстрая загрузка карточек и категорий.
- WebP/AVIF изображения.
- Lazy loading.
- Таблицы характеристик в HTML, не картинкой.
- PDF документов доступны с карточек.
- Open Graph для карточек и категорий.
- Микроразметка.
- 404 и редиректы при переносе старого сайта.
