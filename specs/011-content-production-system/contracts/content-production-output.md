# Contract: Content Production Output

## Knowledge Page Contract

Each knowledge page must render:

- intro paragraph;
- at least two content sections;
- FAQ block;
- links to catalog/solution pages;
- `FAQPage` JSON-LD.

## Category Page Contract

Each category page must render:

- product listing;
- selection guidance;
- FAQ block;
- `ItemList` JSON-LD;
- `FAQPage` JSON-LD.

## Document Contract

`07-build-specifications/content-production-plan.md` must define:

- first-release content priorities;
- templates for category, product, use-case, knowledge, FAQ;
- claim-control rules;
- production workflow.
