# Research: Positioning Copy System

Дата: 2026-05-14.

## Decision: Position Soliton As A Russian Technical Manufacturer, Not A Generic Reseller

Soliton should be presented as a manufacturer with a 15-year known history, Russian production, and practical reliability experience.

## Rationale

The PDU category has many reseller-style catalog pages. A manufacturer position gives Soliton stronger trust, better B2B credibility, and a clearer reason to request a quote instead of comparing only by price.

## Decision: Use Proof-Backed Technical Copy

Claims about registry inclusion, reliability, quality, production, and comparison with APS/APC must be controlled.

## Rationale

Strong claims are valuable, but unsupported claims weaken trust and may create legal or reputational risk. The copy system will provide safe phrasing and proof requirements.

## Decision: Combine SEO Demand With Buyer Intent

Copy must explicitly cover demand clusters:

- PDU / блоки распределения питания;
- блоки розеток 19";
- блоки розеток 1U;
- Schuko / IEC C13 / IEC C19;
- 16A / 32A;
- вертикальные PDU;
- измерительные/мониторинговые/управляемые PDU;
- серверные шкафы, 19" стойки, ЦОД.

## Rationale

The site must attract search traffic and convert it. SEO copy must answer the buying question, not only include keywords.

## Alternatives Considered

### Generic Ecommerce Copy

Rejected because it would erase Soliton's manufacturer trust and technical expertise.

### Aggressive Comparative Copy Against APC/APS

Rejected for the first version unless evidence is provided. The safer approach is testimonial-dependent or softened comparative framing.

### Purely Technical Datasheet Copy

Rejected because technical buyers still need guidance, selection logic, proof, and conversion paths.
