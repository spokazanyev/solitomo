# Contract: `isValidInn`

Новый чистый модуль `apps/web/src/lib/dadata/inn.ts`. Локальная проверка контрольной суммы ИНН (FR-007/FR-008). Без сети.

## API

```ts
/** true только для математически корректного ИНН длиной 10 или 12 цифр. */
export function isValidInn(inn: string): boolean;
```

## Алгоритм (канонический, ФНС)

Вход нормализуется: берутся только цифры (`inn.replace(/\D/g, "")` — или строго проверяется, что строка уже из цифр). Если длина не 10 и не 12 → `false`.

**10 знаков (юрлицо):**
```
weights = [2,4,10,3,5,9,4,6,8]
n10 = (Σ weights[i]·d[i], i=0..8) mod 11 mod 10
valid ⇔ n10 === d[9]
```

**12 знаков (ИП/физлицо):**
```
w11 = [7,2,4,10,3,5,9,4,6,8]
w12 = [3,7,2,4,10,3,5,9,4,6,8]
n11 = (Σ w11[i]·d[i], i=0..9)  mod 11 mod 10
n12 = (Σ w12[i]·d[i], i=0..10) mod 11 mod 10
valid ⇔ n11 === d[10] && n12 === d[11]
```

## Тест-кейсы (`inn.test.ts`)

| Вход | Ожидание | Причина |
|---|---|---|
| `"7707083893"` | `true` | Валидный 10-знак (Сбербанк, публичный) |
| `"500100732259"` | `true` | Валидный 12-знак (ИП, публичный пример ФНС) |
| `"7707083894"` | `false` | 10-знак, неверная контрольная цифра |
| `"500100732250"` | `false` | 12-знак, неверная контрольная |
| `"123456789"` | `false` | 9 цифр — короткий (FR-008: не валиден) |
| `"12345678901"` | `false` | 11 цифр — между 10 и 12 |
| `"abcdefghij"` | `false` | не цифры |
| `""` | `false` | пусто |

## Использование

- `InvoiceCheckoutForm` гейт отправки: `baseLegalReady` использует `isValidInn(inn.trim())` вместо `/^[0-9]{10,12}$/` (data-model §5).
- UI-ошибка под полем ИНН показывается ТОЛЬКО когда длина == 10 или 12 и `isValidInn === false` (FR-008: частичный ввод <10/между 10-12 не считается ошибкой контрольной суммы). При длине 11 поле «незавершённое», ошибку контрольной суммы не показываем (показываем нейтрально/ничего).
- Существующие события `inn_validation_success/failed` ([events.ts:403](../../../apps/web/src/lib/analytics/events.ts)) переключаются с проверки длины на `isValidInn` (errorCode `inn_checksum` при неверной сумме, сохраняя `inn_wrong_length`/`inn_non_numeric`).
