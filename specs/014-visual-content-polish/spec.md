# Feature Spec: Visual And Content Polish

Дата: 2026-05-15.

## Источник

Основано на `07-build-specifications/web-content-design-review.md` и записи реестра `07-build-specifications/document-register.md`.

## Цель

Довести текущий сайт Soliton от аккуратного B2B-прототипа до более публичного ecommerce/RFQ-интерфейса: убрать внутренний язык, усилить доверие, сделать карточки и каталог понятнее для покупателя, поднять конверсию формы КП.

## User Outcomes

1. Пользователь не видит внутренних типов страниц вроде `Conversion`, `Trust`, `B2B`.
2. Карточка товара выглядит как современная товарная страница, а не как импорт прайс-листа.
3. Закупщик быстрее видит реальные документы и путь к запросу недостающих материалов.
4. Пользователь, пришедший из карточки товара в КП, быстрее попадает к форме.
5. Каталог получает следующий план развития: поиск, сортировка, быстрые фильтры, сопоставимые карточки.

## Scope

### In Scope

- публичные бейджи/eyebrow labels страниц;
- нормализация товарных H1 и metadata title;
- compact RFQ hero для `/b2b/request-quote/`;
- перестановка document center так, чтобы реальные файлы были выше;
- обновление спецификаций и QA-документов;
- браузерная проверка ключевых страниц.

### Out Of Scope For This First Pass

- полноценный клиентский поиск по каталогу;
- интерактивная сортировка;
- mobile filter drawer;
- новые доказательные документы, если их нет в исходных данных;
- интеграции с оплатой, доставкой или МойСклад.

## Acceptance Criteria

- На публичных страницах нет видимых `Conversion`, `Trust`, `B2B`, `B2B custom`, `B2B tenders`.
- `/product/sp-8/` показывает H1 в редакторском формате, а metadata title не дублирует SKU.
- `/b2b/request-quote/?sku=SP-8...` показывает форму выше первого экрана, без большого лендингового отступа.
- `/documents/` сразу показывает реальные доступные файлы из карточек товаров.
- `pnpm lint`, `pnpm typecheck`, production build проходят.
