# Research: Visual Design System

Дата: 2026-05-14.

## Decision: Technical Manufacturer Interface, Not Decorative Landing Page

The visual system should communicate manufacturing credibility, engineering clarity, and B2B purchase confidence. It should avoid generic ecommerce decoration and overly playful styling.

## Rationale

PDU buyers need to compare specs, verify documents, and request a quote. Visual design should reduce cognitive load and make technical decisions easier.

## Decision: Product Photography And Technical Data First

Real product photos, close-ups of outlets/inputs, diagrams, and specification tables should be more important than abstract illustrations.

## Rationale

Competitor analysis shows that strong PDU pages rely on product families, specs, documents, selectors, and technical proof. Soliton's product category is inspection-driven.

## Decision: Quiet Industrial Palette With High-Contrast Actions

Use a restrained base palette with clear action colors. Avoid dark-heavy, monochrome blue/slate, purple gradients, beige palettes, and decorative blobs.

## Rationale

The site must feel modern and precise without looking like a generic SaaS landing page. Conversion actions must be easy to identify.

## Decision: Dense But Organized Content

Use compact, scan-friendly components for specs, filters, cards, and B2B forms. Avoid oversized marketing cards where technical comparison is required.

## Rationale

Technical buyers and procurement users scan many details. The UI should support repeated comparison and data density.

## Alternatives Considered

### Marketing Hero With Abstract Visuals

Rejected because it would obscure the actual product and reduce technical trust.

### Minimal Catalog-Only Design

Rejected because Soliton needs manufacturer positioning, trust, and conversion storytelling.

### Heavy Dark Industrial Theme

Rejected because it risks poor readability and a one-note palette.
