# Contract: UI Design System Output

Дата: 2026-05-14.

## Required Output File

`07-build-specifications/ui-design-system-spec.md`

## Required Sections

1. Executive summary.
2. Visual character.
3. Design principles.
4. Design tokens.
5. Layout and responsive grid.
6. Typography.
7. Color and state rules.
8. Imagery and visual asset rules.
9. Component patterns.
10. Page patterns.
11. Conversion hierarchy.
12. Accessibility and no-overlap rules.
13. QA checklist.
14. Inputs for next SDD features.

## Minimum Counts

- At least 10 component patterns.
- At least 8 page patterns.
- At least 4 primary buyer actions in conversion hierarchy.
- Responsive rules for desktop, tablet, and mobile.

## Quality Rules

- Design must support technical density.
- Real product visuals must be preferred over abstract decoration.
- Tables, forms, filters, and cards must have stable dimensions and no text overlap.
- B2B/RFQ flows must be visually first-class.
- SEO content must be integrated without creating a cluttered page.
